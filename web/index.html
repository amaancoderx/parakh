    Authentication
    
            
    Send your key in the api-subscription-key header, the same header Sarvam uses. Every key gets 10 free minutes of audio. Make one on the Developers page.
    
            
    api-subscription-key: pk_your_key
    
            
    A missing, unknown or revoked key gets 401. A key that has used its minutes gets 402.
    
          
    

          
    
            
    POST/speech-to-text
    
            
    Check a clip
    
            
    Send one clip of up to 30 seconds. Parakh has three speech models hear it, finds the words they disagree on, checks those against the names you know, and gives back a transcript you can act on.
    
            
    Body multipart/form-data
    
            
    
              
    filerequiredThe audio. WAV, MP3, M4A, OGG or WebM, up to 30 seconds and 12 MB.
    
              
    namesstringNames this caller knows: contacts, places, brands. Commas or new lines.
    
              
    userstringYour id for the person. Names they confirmed earlier are used too.
    
              
    streambooleantrue sends the base transcript first, then the checked one, as JSON lines. Default false.
    
              
    transcriptstringYour own recogniser's text for this clip. Parakh checks it instead, and calls one model fewer.
    
              
    budget_msintegerHow long after the draft to wait for the other models. A slower one is left out. 0 waits for all.
    
              
    modestringtranslit, the only mode in this version: Roman script out.
    
            
    
            
    Request
    
            
    
          
    

          
    
            
    Streaming
    
            
    With stream=true the answer comes as application/x-ndjson, one JSON object per line. Show the draft at once, then swap in the checked text when it lands.
    
            
    
              
    1
    draftThe base model's own words, untouched. About a second.
    
              
    2
    verifiedThe checked transcript, with the evidence for every change. The full response below.
    
            
    
            
    {"event": "draft", "request_id": "c26c15f5…", "model": "Saaras v4",
 "transcript": "Teen ka kyon lo phir? Aishar mein lo…", "ms": 992}
{"event": "verified", "request_id": "c26c15f5…",
 "transcript": "Teen ka kyon lo phir? Eicher mein lo…", "parakh": {…}}
    
          
    

          
    
            
    Response
    
            
    Sarvam's fields at the top level, so existing code keeps working. Everything Parakh adds is under parakh.
    
            
    
              
    transcriptstringThe checked transcript.
    
              
    parakh.baseobjectWhich model wrote the draft, and its words.
    
              
    parakh.editsarrayEvery word Parakh changed: from, to, why, and what each other model heard.
    
              
    parakh.confirmarrayWords it would not settle alone. Ask the caller before acting on them.
    
              
    parakh.clearbooleantrue when nothing is left to confirm: safe to act on.
    
              
    parakh.formattedstringThe same text with numbers written as digits.
    
              
    parakh.timing_msobjectWhen the draft and the checked answer were ready.
    
            
    
            
    {
  "request_id": "c26c15f54e1647c591be4f6e062f3ae1",
  "transcript": "Teen ka kyon lo phir? Eicher mein lo to chaar ka hi lo…",
  "timestamps": null,
  "diarized_transcript": null,
  "language_code": null,
  "parakh": {
    "base": { "model": "Saaras v4", "transcript": "Teen ka kyon lo phir? Aishar mein lo…" },
    "formatted": "…chaar mein humse 40 set ya 42 set kareeb…",
    "edits": [{
      "from": "Aishar",
      "to": "Eicher",
      "why": "a name you know; another recogniser heard something close",
      "heard": { "Saaras v3": "Aishwarya", "gpt-transcribe": "आईशर" }
    }],
    "confirm": [],
    "clear": true,
    "recognisers": ["Saaras v4", "Saaras v3", "gpt-transcribe"],
    "left_out": [],
    "extra_listens": 0,
    "timing_ms": { "draft": 992, "verified": 2730 }
  }
}
    
          
    

          
    
            
    Errors
    
            
    Errors come back as JSON with a detail message you can show.
    
            
    
              
    400The audio could not be read, was empty, or mode was not translit.
    
              
    401Missing, unknown or revoked API key.
    
              
    402This key has used its free minutes.
    
              
    413The clip is longer than 30 seconds or larger than 12 MB.
    
              
    429Too many keys: a workspace can hold 10.
    
              
    500Something failed on our side. Safe to retry.
    
            
    
          
    

          
    
            
    POST/api/keys
    
            
    Create a key
    
            
    JSON body with a label and your workspace user. The full key is in this answer only; after that it is shown as pk_xxxx...xxxx.
    
            
    { "label": "Production", "user": "u-1234" }
→ { "key": "pk_4d99…8d71", "id": "4d99bd93", "label": "Production", "minutes_left": 10, … }
    
          
    
          
    
            
    GET/api/keys/{key}
    
            
    Key usage
    
            
    Minutes used and left, requests made, and when the key was last used.
    
          
    
          
    
            
    GET/api/users/{user}/keys
    
            
    List keys
    
            
    A workspace's keys, newest first, masked, with usage. Never the full key.
    
          
    
          
    
            
    DELETE/api/users/{user}/keys/{id}
    
            
    Revoke a key
    
            
    The key stops working at once. Only its own workspace can revoke it.
    
          
    
          
    
            
    GET/api/health
    
            
    Health
    
            
    Which speech models are live on this server.
    
            
    { "ok": true, "recognisers": ["Saaras v4", "Saaras v3", "gpt-transcribe"] }
