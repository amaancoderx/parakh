The trust layer for voice AI

Voice AI hears. Parakh checks.

Speech models mishear the names a business acts on: "Aishar" for an Eicher truck. Parakh has three models hear the audio, checks the words they disagree on, and fixes only what it can prove.

5Read this honestly

!Ties a keyword feature on accuracy (p 0.39 to 0.73). Its edge is safety and proof.
!Its questions miss some of its own mistakes: 9 of 179 unflagged recordings had a wrong name.
!No gain on IndicContextEval (lecture speech): 82.0% against 82.3%.
!Two rules changed after the first public set. The 189-recording set ran once, after.

Built by me

  • The Parakh harness: three-model check, sound matching, re-listening, number rules
  • Memory with the daily learning run
  • The API, keys and metering
  • The web app, evaluation, deployment

Reused

  • Sarvam Saaras v3, v4 and OpenAI gpt-transcribe
  • OpenAI text models for summary and name lookup
  • Google FLEURS Hindi for testing
  • FastAPI, AWS EC2, Caddy

Simulated, and why

  • Real trader calls; saved model answers replayed so the demo is instant
  • Trader's week: real calls, days and nights run back to back
  • Test ledger written for the test
  • No sign-in, so anyone can try it
